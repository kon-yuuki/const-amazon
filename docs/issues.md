# Const MVP Issue List

最終更新: 2026-02-15

## 共通品質条件（Best Practices埋め込み）

以下は全Issueで参照する共通条件。出典は `docs/best-practices.md`。

- `BP-01`: `NEXT_PUBLIC_`を最小化し、Gemini APIキーをクライアントに露出しない
- `BP-02`: `fetch`全箇所にキャッシュ方針（`no-store` / `revalidate` / `revalidateTag`）を明示
- `BP-03`: インポートAPIでJSON Schema + Zod検証
- `BP-04`: 429/5xxの再試行ポリシー実装（上限回数・指数バックオフ）
- `BP-05`: IndexedDBデータに`schemaVersion`を追加
- `BP-06`: `navigator.storage.persist()` 実行と結果表示
- `BP-07`: Service Worker更新通知UI（再読み込み導線）
- `BP-08`: セキュリティヘッダー（CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy）設定
- `BP-09`: 共有URL復元の失敗ハンドリング（壊れたURL時）
- `BP-10`: 共有データ形式にバージョン情報（例: `v=1`）を同梱
