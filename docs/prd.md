# 日用品固定費化アプリ『Const』仕様書

## 1. コンセプト

「管理のいらない家計管理」

Amazon定期便のデータを可視化・予測することで、不定期に発生する「日用品代」を月額固定の「インフラ費」へと昇華させる。

## 2. ターゲット

- Amazon定期便を多用しているが、毎月の請求額がバラバラで困っている人。
- 家計簿をつけるのが面倒だが、将来の支出は把握しておきたい人。
- 自分のDBに個人情報を預けたくない、あるいは預かりたくないエンジニア。

## 3. 技術スタック

| カテゴリ | 選定テクノロジー | 理由 |
| --- | --- | --- |
| Frontend | Next.js (App Router) | Vercelとの親和性、API Routesの活用。 |
| Hosting | Vercel | デプロイ・運用コスト0円（Hobbyプラン）。 |
| AI (OCR) | Gemini 1.5 Flash | 0円で運用可能。画像・テキストから配送情報を構造化。 |
| Storage | IndexedDB (Dexie) | ユーザー端末内に永続保存。構造化データの管理と拡張性を確保。 |
| Logic | Lz-string | データをURLに載せるための高圧縮ライブラリ。 |
| PWA | next-pwa | アプリ化によるデータ生存率の向上。 |

## 4. 主要機能詳細

### A. AIスマート・インポーター

- テキスト入力: Amazonの「定期おトク便」管理画面を全選択コピペして貼り付けるだけ。
- スクショ入力: スマホのスクショをアップロード。
- 処理: Gemini APIが「商品名・価格・配送頻度（週/月）・次回配送予定日」を抽出し、JSONで返却。

### B. 固定費化シミュレーター

- 月別支払い予測: 向こう6ヶ月の「合計支払い額」をグラフ表示。
- 平均化ロジック: 年間の合計額を12で割り、「実質月額いくら払っているか」を算出。
- メンバー按分機能:
  - 家計メンバーを任意人数で追加できる。
  - デフォルトは均等割り（折半含む）で、`合計月額 ÷ メンバー数` を各メンバー負担額として表示。
  - 均等でない場合は、メンバーごとに任意の負担比率（%）を設定して月額を再計算できる。
  - 比率合計は100%でバリデーションする。
- 目的: 日用品を完全な固定費として脳内処理可能にする。

### C. 「サーバーレス」共有システム

- 共有URL発行: 保存された全データを圧縮・Base64化し、URLに埋め込む。
- メリット: DBを使わないため、紺野さんのサーバーにデータは一切残らない。
- 受信側挙動: URLを受け取った側は、その瞬間のデータを自分のブラウザにインポートできる。

### D. PWA（プログレッシブ・ウェブ・アプリ）

- 永続性: `navigator.storage.persist()` を叩き、OSのクリーンアップ対象から外れるようリクエスト。
- オフライン: 電波がなくても、保存済みのスケジュールはいつでも確認可能。

## 5. 画面構成イメージ

- Dashboard: 今月の合計額、次回の配送日、向こう半年の支出グラフ。
- Household Settings: メンバー追加・削除、均等割り/任意比率の設定。
- Item List: 登録アイテム一覧（編集・削除可能）。
- Import: テキスト/画像からAIで読み込むUI。
- Share: 共有・バックアップ用URLの生成画面。
